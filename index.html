My experience spans:

In my Agile Lead role, I coordinate delivery across four squads, aligning priorities, capacity, milestones, risks and cross-team dependencies. I work closely with Product Owners, engineering leaders and stakeholders to strengthen delivery predictability, transparency and team ownership.

UC-01
Jira Automation Jira Smart Values Webhook Power Automate Microsoft Teams JSON

Automated Sprint Completion Summary

Problem

Sprint completion reporting required manually retrieving delivery metrics from Jira and communicating results to the team, creating repetitive effort and inconsistent reporting.

Automation

When a sprint completes, Jira Automation collects metrics, builds a JSON payload, and sends it via webhook to Power Automate — which formats and publishes the summary to Microsoft Teams.

UC-02
Jira Automation Webhook Power Automate Routing Logic Microsoft Teams JSON

Multi-Squad Dynamic Channel Routing

Problem

Multiple squads needed automation notifications delivered to their own Teams channels. Maintaining a separate flow per squad created duplication and growing maintenance overhead.

Automation

One shared Jira-to-Power-Automate integration uses Switch/Condition routing logic to identify the squad from the payload and dynamically deliver the notification to the correct Teams channel.

UC-03
Jira Automation Webhook Power Automate Adaptive Cards Microsoft Teams JSON

Ready-for-Rollout Notification

Problem

When work became ready for rollout, relevant people needed timely visibility without relying entirely on manual messages or checking Jira.

Automation

When a Jira issue transitions to "Ready for Rollout", Jira Automation sends a webhook to Power Automate, which formats and delivers a structured Teams notification with key issue details.

UC-04
Jira Automation Webhook Power Automate Microsoft Teams JSON

New Bug Alert Automation

Problem

Newly reported bugs had no automatic visibility. Teams depended on someone manually posting to a channel, meaning defects could sit unnoticed until the next standup or check-in.

Automation

When a Bug is created in Jira, Jira Automation validates the issue type, extracts key bug details, and sends a structured JSON payload via webhook to Power Automate, which formats and delivers an alert to Microsoft Teams.

UC-05
Power Automate Adaptive Cards Microsoft Teams JSON Webhook

Dynamic Microsoft Teams Adaptive Cards

Problem

Plain text automation notifications are difficult to scan and provide limited structure for operational information delivered to Microsoft Teams.

Automation

Power Automate receives a JSON payload from Jira via webhook, maps dynamic values, and constructs a structured Adaptive Card posted to Microsoft Teams — transforming raw data into a readable, actionable notification.

Jira to Power Automate Webhook Integration

Pattern

A technical deep-dive into the reusable integration pattern that underpins all Flow Craft automations — how Jira Automation triggers external workflows by sending structured data through a webhook.

Why it matters
