TK-06 Template Automation

JSON / Webhook Payload Starter Template

Provide a safe starter structure for designing JSON payloads passed between workflow systems through webhooks.

1. WHAT IS THIS?

JSON (JavaScript Object Notation) provides a lightweight, structured format for exchanging data between systems. These starter templates ensure your event payloads are clean, predictable, and decoupled from any specific tool.

2. ISSUE EVENT TEMPLATE

A generic, sanitized template for single-issue updates (e.g., passing issue data from Jira to Power Automate).

{
  "eventType": "issue.updated",
  "issueKey": "DEMO-123",
  "summary": "Example issue summary",
  "status": "Ready",
  "team": "Example Team",
  "assignee": "Example User",
  "timestamp": "2026-01-01T10:00:00Z"
}
  • eventType: Tells the receiving system what happened.
  • issueKey: Unique identifier for cross-reference.
  • summary, status, team, assignee: Key business context required for routing or notifications.
  • timestamp: ISO 8601 formatted time of the event.

3. SPRINT EVENT TEMPLATE

A generic template for aggregated events, such as sprint reporting or cycle closures.

{
  "eventType": "sprint.completed",
  "sprintName": "Sprint 10",
  "sprintGoal": "Example sprint goal",
  "storyCount": 8,
  "bugCount": 2,
  "taskCount": 3,
  "spikeCount": 1,
  "totalCount": 14,
  "storyPoints": 34
}

4. PAYLOAD DESIGN PRINCIPLES

  • Use meaningful property names (e.g., storyCount instead of just stories).
  • Enforce a consistent naming convention (camelCase is highly recommended for JSON).
  • Maintain predictable data types (keep strings as strings, numbers as numbers).
  • Send only required information to minimize payload size and complexity.
  • Avoid unnecessary sensitive data.
  • Validate required fields before sending the payload.
  • Version payloads if integrations become complex and contracts evolve (e.g., adding a version: "1.0" field).

5. SECURITY

Never include the following in unencrypted webhooks:

  • Passwords
  • API tokens
  • Authentication secrets
  • Production webhook URLs
  • Unnecessary personal or sensitive information
