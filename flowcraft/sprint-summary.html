Automated Sprint Completion Summary

Jira Automation Webhook Power Automate Microsoft Teams JSON

Problem

At the end of every sprint, teams spent time manually compiling completion stats, pulling numbers from Jira, and copy-pasting them into Teams — a repetitive, error-prone process that delayed post-sprint communication.

Automation

A Jira Automation rule fires when a sprint completes, builds a JSON payload of sprint metrics, and sends it to a Power Automate webhook. Power Automate formats a structured summary card and posts it directly to the team's Microsoft Teams channel — no manual effort required.

Technology Stack

  • Jira Automation — trigger on sprint completion, build JSON payload
  • Webhook — HTTP POST to Power Automate endpoint
  • Power Automate — receive, format, and route the summary
  • Microsoft Teams — destination channel for the summary card
  • JSON — data structure carrying sprint metrics
